fixed:
  - title: "Update PLUS modal could not be scrolled"
    detail: "The dialog body relied on flex sizing while the underlying dialog primitive uses a grid layout, so the scroll container never received a bounded height. With overflow hidden on the dialog, long preview tables were cut off and the Cancel / Run update buttons were pushed out of view. The dialog is now an explicit flex column with a non-shrinking header and footer, so the mapping list scrolls as intended."

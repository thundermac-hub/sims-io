summary: "Every API route that read a JSON body through an unchecked type cast now validates it with a schema first — malformed requests get a clear 400 instead of a crash, and status fields can no longer write junk into database enum columns."
improved:
  - title: "All 34 unchecked body casts converted to schema validation"
    detail: "Auth, users, profile, tickets, ticket categories, leads, deals, activities, sales appointments, onboarding appointments, ClickUp task requests, Google Places, and the PLUS tools now parse request bodies with colocated Zod schemas via a shared parseJsonBody helper. Valid requests behave exactly as before; malformed JSON or wrong-typed fields return a 400 with a clear message instead of an unhandled 500."
fixed:
  - title: "Ticket status writes are constrained to real statuses"
    detail: "The ticket update endpoint previously accepted any string into the status field, which silently corrupted the analytics grouping — it now only accepts the four real ticket statuses. Enum-backed fields on leads, deals, and activities are validated against the same tuples the rest of the code already uses."

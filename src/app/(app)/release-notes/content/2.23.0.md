title: "Project Tracker: projects, phases, and activities"
summary: "A new Project Tracker module lets teams run multiple projects inside SIMS, each broken into phases and activities with per-project Owner, Editor, and Viewer access. Deleting a phase or activity is always reversible."
new:
  - title: "Project Tracker module"
    detail: "Create and manage multiple concurrent projects from the new Project Tracker page in the General workspace. Each project has a name, description, and start date, and the person who creates it becomes the Project Owner."
  - title: "Per-project access: Owner, Editor, Viewer"
    detail: "Owners and Editors can add other SIMS users to a project as Editors (can change project content) or Viewers (read-only). People without a role on a project cannot see it at all. Super Admins keep read-only visibility on every project for support purposes, but cannot change project content."
  - title: "Phases and activities with status tracking"
    detail: "Break a project into phases, then add activities under each phase. Every phase and activity has a status (Not Started, In Progress, Blocked, Completed), an optional assignee drawn from the project's members, and optional start and due dates."
  - title: "Reversible delete"
    detail: "Deleting a phase or activity hides it from the default view but keeps the record, including its history. Use \"Show deleted\" to see hidden items and restore them. Deleting a phase hides its activities too; restoring the phase brings back every activity that was not deleted in its own right."
improved:
  - title: "Confirmation before completing unfinished phases"
    detail: "Marking a phase Completed while one or more of its activities are still open now asks for explicit confirmation and lists which activities are outstanding."

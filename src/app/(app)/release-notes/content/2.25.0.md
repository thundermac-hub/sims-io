version: "2.25.0"
date: "2026-07-30"
title: "Project diagram becomes the workspace for building a project"
summary: "Phases and activities are now created directly on the project diagram, and dependencies are made by dragging a connection between nodes. Nodes show dates and assignees, phases missing from the sequence are flagged, and the canvas gains a zoom slider."
new:
  - title: "Build the project on the diagram"
    detail: "\"New phase\" now lives on the Diagram tab, and every phase node carries an \"Add activity\" action. This is where a project gets laid out; the Overview list remains the place to update status, edit, delete, and restore."
  - title: "Link items by dragging a connection"
    detail: "Drag from a node's right edge to another node's left edge to make the second item depend on the first. The existing rules still apply — self-links, duplicates, loops, and a phase depending on its own activity are all rejected with an explanation."
  - title: "Unlinked phase warning"
    detail: "A phase with no dependency connection to another phase is flagged on its node and counted in the diagram header, so no phase is accidentally left out of the sequence. Links to activities do not count — the phase chain is the project's backbone. A project with only one phase is exempt."
  - title: "Dates and assignee on the node"
    detail: "Nodes now show the item's start and due dates when set, along with the assigned member, so the schedule is readable straight from the diagram."
  - title: "Zoom slider"
    detail: "The canvas has a zoom slider with plus/minus steps, a live percentage, and a Fit button, replacing the previous zoom buttons. It stays in step with scroll and pinch zooming."
improved:
  - title: "Line style now shows what an edge connects"
    detail: "Solid lines join two phases; dotted lines mean an activity is involved at one or both ends. Colour continues to carry the dependency state — amber while the prerequisite is outstanding, green once it is Completed. Activity nodes are outlined with a dashed border to match."
fixed:
  - title: "Project date fields use the standard date picker"
    detail: "The project start date and the phase/activity start and due dates now use the same calendar picker as the rest of SIMS, instead of the raw browser date input."
breaking_changes: ""

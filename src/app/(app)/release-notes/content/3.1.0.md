version: "3.1.0"
date: "2026-08-27"
title: "Locked-down file storage and uploads"
summary: "Stored files are now addressed by a single validated key grammar with per-file ownership checks, served with safe headers, and uploads are verified by content — not by whatever name or type the client claims."
new:
  - title: "One grammar for storage keys"
    detail: "Every object key is validated against a single parser (allowlisted folder, numeric or public owner, timestamp-random stem, short extension) before it reaches storage or a database lookup. Path traversal and arbitrary-key reads and deletes are structurally impossible."
  - title: "Ownership model for stored files"
    detail: "Your own files are always readable and deletable. Avatars stay visible to all signed-in users. Everything else requires the matching page access and the file must be referenced by a record you can already see — support-form attachments on tickets, onboarding attachments for reviewers, ClickUp task-request attachments for approvers. Denials return 404 so file names can't be enumerated. Deletion never crosses users."
  - title: "Uploads verified by content"
    detail: "Uploads are sniffed by magic bytes; the detected type — not the filename — decides the stored content type and extension. Images, PDFs, spreadsheets (xlsx/xls/csv), and Word documents (doc/docx) are allowed for staff uploads; avatars accept images only; the public support form keeps its stricter list. File pickers now filter to the allowed types up front, and uploads are rate-limited per user and IP."
improved:
  - title: "Attachment viewing is safer"
    detail: "The file-view endpoint now re-derives the content type from the validated key, serves user content with a hard sandbox (CSP), marks responses private and uncacheable, and sends files that aren't images or PDFs as downloads instead of rendering them."
  - title: "PLUS spreadsheet endpoints check ownership"
    detail: "The PLUS preview, update, and cleanup endpoints validate the upload key and only operate on files the caller uploaded. Onboarding appointment attachments are validated the same way on create and edit."
  - title: "Faster attachment authorization lookups"
    detail: "Migration 026 adds prefix indexes on the attachment columns so the reference check is an index seek, not a scan."

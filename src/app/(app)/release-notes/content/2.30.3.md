version: "2.30.3"
date: "2026-08-27"
title: "Test discovery, Node pins, and shared validation plumbing"
summary: "Tests are now discovered by pattern instead of a hand-maintained list, the Node version is pinned consistently, and shared error-envelope and Zod validation helpers are in place for the security hardening work that follows."
improved:
  - title: "Tests are discovered automatically"
    detail: "npm test now runs every colocated .test.ts/.spec.ts file via a glob instead of a hardcoded 29-file list, so a new test file can no longer be silently skipped. A typecheck script (tsc --noEmit) was added alongside it."
  - title: "One Node version everywhere"
    detail: "The Node version is now pinned in .nvmrc (22.21.1), package.json engines (>=22.18.0, the floor for unflagged type stripping), and the Dockerfile base image, so local dev, CI, and the deploy image can no longer drift apart."
  - title: "Shared API error envelopes and request validation"
    detail: "New src/lib/api-errors.ts codifies the { error } response shape all routes already use (including Retry-After on 429 and a serverError helper that logs internally and returns a generic message). New src/lib/validation.ts brings Zod-based parseJsonBody / parseSearchParams / parseFormData helpers plus shared field primitives, so malformed request bodies return a 400 instead of an unhandled 500."
  - title: "Future enum syntax fails at compile time"
    detail: "tsconfig now sets erasableSyntaxOnly, so TypeScript syntax that Node's type stripping cannot erase (like enum) becomes a clear compile error instead of a runtime SyntaxError in tests."

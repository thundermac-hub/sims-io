improved:
  - title: "The link stands on its own line"
    detail: "Both the automatic send on ticket close and the manual share button now put a blank line before the survey link, so it reads as a clear call to action rather than trailing off the end of a paragraph. Nothing follows the link, which is also what gives a chat app the best chance of turning it into a preview card."
  - title: "The survey page can render as a preview card"
    detail: "The CSAT page now serves Open Graph tags — a title, a short description, and the Slurp logo — so a shared link can appear as a card instead of a raw URL. Opening a link to build that card is harmless: the page only reads the token, and a survey link is still marked used only when the survey is actually submitted, so a preview can never consume a merchant's single-use link."
fixed:
  - title: "One copy of the survey message, not two"
    detail: "The message wording was duplicated between the automatic send and the manual share button, so editing it would have changed only one of them. Both now read from the same place and can no longer drift apart."

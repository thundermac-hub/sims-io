fixed:
  - title: "Migration runner ships with its database driver"
    detail: "Next.js compiles mysql2 into the application's server bundle, so it never appears in the standalone node_modules the migration runner could resolve from — the post-deployment command failed with a module-not-found error. The Docker image now installs a dedicated mysql2 copy under scripts/node_modules (scoped so it can't collide with the app's traced dependency tree), and the CI image check now imports the driver from the runner's directory instead of only checking that files exist. Verified by running a real baseline and up from inside the built image."

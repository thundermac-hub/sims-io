title: "Fresh schema imports work again"
summary: "A fresh import of schema.sql failed on MySQL 8.4 because one foreign-key column's signedness didn't match the column it references; the migration acceptance run caught it."
fixed:
  - title: "clickup_task_request_attachments foreign key signedness"
    detail: "The table declared its id and clickup_task_request_id as signed BIGINT while the referenced clickup_task_requests.id is BIGINT UNSIGNED — MySQL requires exact signedness agreement, so a fresh schema.sql import aborted at that table (and everything after it never loaded). Both columns are now UNSIGNED, keeping schema.sql self-consistent for fresh imports. Existing databases are unaffected; this only changes the fresh-import template."
